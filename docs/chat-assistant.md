# 对话剪辑助手

Web 页面面向本机创作者：创建项目、拖放导入视频（可选 SRT/VTT）、执行分析、输入剪辑需求、审阅候选并确认后生成预览或 MP4。浏览器不需要知道本地路径、素材 ID 或 JSON；底层 HTTP 路由仍只监听 loopback。

助手始终从带来源的 Evidence 中检索候选；不会在没有确认的情况下修改时间线。支持的首批目标：

- `剪成 1 分钟高能集锦` → `highlights`，查询高能，保留目标时长
- `找出所有笑点` → `jokes`，查询笑
- `保留进球和庆祝` → `sports`，查询进球/庆祝
- `删掉开场和片尾` → `trim_ends`，等待时间线确认
- `生成预览` → `preview`，等待候选方案确认
- 一般主题请求（如“保留产品发布的掌声，剪成 30 秒”）→ `select`，由文本模型提取检索词与目标时长；无模型时保留本地规则支持的常见请求

## 为什么参考 GoClip

GoClip 的高光不是让模型直接输出剪辑时间线，而是：

1. 由媒体层统一抽帧并绑定源时间；
2. 字幕/视觉分析返回候选事件和证据；
3. 严格校验模型返回的时间必须落在已提供帧或字幕范围内；
4. 对最高分候选做局部复核；
5. 只用经过验证的场景生成草稿，最后由用户确认再导出。

Video Agent 第一版复用了其中最重要的边界：`Evidence` 是唯一来源、对话只产生意图和候选、编辑必须经过 proposal/确认。后续再补候选评分、局部视觉复核和自动生成时间线。

文本模型配置优先读取 `VIDEO_AGENT_TEXT_*`，否则读取 GoClip 的 `AUTOCLIP_TEXT_*`；视觉分析优先读取 `VIDEO_AGENT_VISION_*`，否则读取 `AUTOCLIP_VISION_*`。百炼可使用 `qwen-plus`、`qwen-vl-plus` 和 `qwen-audio-3.1-asr-flash`；ASR 使用 `AUTOCLIP_ASR_*`，服务端将音频切成不超过四分钟的片段并读取逐句时间戳。

# 产品路线图

本路线按用户价值组织，不再以 P1–P4 作为产品叙事。旧阶段、协作拆分和验收记录保留在历史文档中，用于追溯工程演进，不代表当前产品承诺。

## 当前：证据驱动的对话选片闭环

- 本地导入长视频与字幕，支持可选 ASR/视觉分析。
- 生成带时间范围的 Evidence，按主题检索候选。
- Web 中创建项目、上传、分析、生成方案、确认、预览和导出。
- SQLite revision、异步渲染、FFmpeg 元数据与完整解码验证提供可靠底座。

## 下一步：精确控制与质量

1. **局部对话编辑**：草稿方案已支持逐条修改、确认和版本恢复，对应 `/v1/ui/proposals` 一组端点；Web 目前是对话式草稿界面，可视化时间线和片段级操作还在下一步。
2. **更强理解**：场景切分、句级 ASR 对齐、embedding、去重与候选排序，提升长视频高光质量。
3. **成片表达**：字幕、BGM/混音、竖屏构图和基础节奏控制。
4. **稳定交付**：模型成本/隐私提示、任务恢复、重试、清理和真实素材回归集。

每项能力都以“是否让创作者更准确、更快地控制长视频剪辑”为取舍标准；CLI/MCP/外部 Agent 适配仅在服务于此目标时投入。

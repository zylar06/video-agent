Video Agent
仅在这台电脑处理你的素材 · 打开对话助手 →

从素材到第一版剪辑，只需要说清楚你想保留什么。

上传视频后，助手会基于字幕或本地配置的语音模型找到有来源的片段。每次修改都要由你确认。

开始一个项目给这支视频起个名字。
加入素材MP4、MOV 或 M4V；可选上传已有字幕。
把视频拖到这里视频会保存到这台电脑的项目目录。
先创建项目，再选择一段视频。
理解素材需要字幕，或在服务端配置百炼 ASR。
导入后点击分析。若没有字幕，请在本机配置 AUTOCLIP_ASR_*；密钥不会发送到浏览器。启用模型时，音频片段和代表帧会发送到你配置的 provider。
告诉助手例如“保留进球和庆祝，剪成 45 秒”。
预览与导出确认方案后生成可播放预览。

确认剪辑方案后，这里会显示预览和导出选项。
